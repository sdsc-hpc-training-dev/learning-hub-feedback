# HPC Learning Hub Feedback

Public bug reports and feature requests for the [SDSC HPC Learning Hub](https://learning-hub.sdsc.edu/).

## Report a bug or request a feature

1. Search existing [issues](https://github.com/sdsc-hpc-training-dev/learning-hub-feedback/issues) to avoid duplicates.
2. Choose [Bug report or Feature request](https://github.com/sdsc-hpc-training-dev/learning-hub-feedback/issues/new/choose).
3. Describe the problem and what you expected. For bugs, include steps we can reproduce, the affected page, and optional browser details or screenshots.

A GitHub account is required to submit an issue. Issues, comments, and attachments are public and linked to your GitHub account. For short, anonymous feedback about your experience, use the Learning Hub's **Give feedback** link instead.

## Keep reports safe

Do not include passwords, API keys, tokens, database connection strings, personal information, or confidential training/research data. Remove sensitive information from screenshots and logs before posting them.

**Do not report security vulnerabilities in a public issue.** Contact [SDSC](https://www.sdsc.edu/contact.html) privately and request the appropriate security contact. See [SECURITY.md](SECURITY.md).

This repository contains feedback and issue templates, not the application source code. Maintainers may ask follow-up questions, apply labels, or close duplicate reports. Feature requests are suggestions, not delivery commitments.
