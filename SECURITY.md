# Security reports

Please do not post suspected vulnerabilities, credentials, or sensitive information in public issues or attachments.

Use the [SDSC contact page](https://www.sdsc.edu/contact.html) to request a private security reporting channel. Describe the general concern without sending passwords or tokens through an unverified channel.

If you accidentally publish a credential, revoke or rotate it immediately and notify the maintainers. Deleting an issue or comment is not a substitute for rotating a leaked credential.
